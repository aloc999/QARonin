# Exploratory Agent — random-walk clicker over RoninShop

A planned extension of the deterministic ReAct loop in `agent.py`: instead of
answering a task, the agent **wanders the shop UI at random**, records every
distinct path it discovers, and logs anything new to
`reports/exploratory/`. Goal: surface untested routes (orphan pages, dead
buttons, missing error states) that scripted tiers never visit. Design-only
for now — no implementation yet; when built it must reuse `TOOLS`, the JSONL
trace format, and the offline-first discipline of `agent.py`.

## Loop

1. Start at `/products` (seeded catalog, 8 items).
2. Collect interactables in the viewport: `a[href]`, `button`, `input`,
   `[data-testid]`. Filter out anything matching the denylist (logout,
   destructive admin actions — see Safety).
3. Pick uniformly at random (seeded RNG: `EXPLORATORY_SEED`, default `7`, so
   runs are reproducible).
4. Act (click/fill with generated values), wait for `networkidle`, record:
   `{from_url, action, selector, to_url, status}`.
5. A path signature is **new** when `to_url + action` is absent from the
   baseline (`reports/exploratory/baseline.json`, committed, regenerated by
   running with `EXPLORATORY_UPDATE_BASELINE=1` after intentional UI changes
   — same policy as visual baselines).
6. Stop after `EXPLORATORY_STEPS` (default 200) or 3 consecutive errors.

## New-path log (`reports/exploratory/exploratory-<stamp>.jsonl`)

```json
{"ts": "2026-09-14T00:00:00+00:00", "from": "/products", "action": "click",
 "selector": ".card.product[data-product-id=\"3\"] .add-to-cart",
 "to": "/products", "new_path": true, "note": "badge incremented"}
```

`new_path: false` rows are debug only; triage starts from the `true` rows.
Each new path becomes either a scripted case (with tier + owner) or a
wontfix note in the same file — no silent drops.

## Safety rails

- Same SQLite seed isolation as every other framework; never point at shared data.
- Denylist by default: logout, order submit, admin endpoints. Order submit
  runs only with `EXPLORATORY_ALLOW_ORDERS=1`, and then against a throwaway DB.
- No fixed sleeps (`make lint-tests` applies here too): `networkidle` +
  auto-retry assertions only.
- A run that finds zero new paths is a PASS, not a failure — it means the
  scripted tiers already cover the reachable surface.

## Run (once implemented)

```bash
make target-up
EXPLORATORY_SEED=7 EXPLORATORY_STEPS=200 python ai-agents/tool-loop/exploratory.py
ls reports/exploratory/
```
