# Document Control (QMS-DC-001, v1.0)

## Versioning

- QMS docs are versioned in git; every change needs a commit + PR review.
- Version format MAJOR.MINOR (major = policy change, minor = clarification).
- The header table of each doc carries Doc ID, version, owner, review date.
