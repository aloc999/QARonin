# QARonin Quality Management System (QMS)

Formal test governance aligned to **ISO 9001:2015** (quality management),
**ISO/IEC/IEEE 29119** (software testing), and **ISO 13485-style** document
control (adapted for non-medical software: versioned, approved, traceable).

| Doc | File | Purpose |
|-----|------|---------|
| Quality Manual | QUALITY-MANUAL.md | Quality policy, objectives, roles, scope |
| Test Process SOP | SOP-TEST-PROCESS.md | Step-by-step test process (plan/design/execute/report) |
| Traceability Matrix | TRACEABILITY-MATRIX.md | Requirements -> cases -> automation (incl. AutomationExercise mapping) |
| Validation Plan | VALIDATION-PLAN.md | Release validation, 30-min regression gate |
| Document Control | DOC-CONTROL.md | Versioning, approvals, change history |

Version: 1.0 | Owner: QA Lead | Review cycle: quarterly.
